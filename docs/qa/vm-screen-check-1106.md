## 남은 문제 (고치지 않음)

- 접수 번호가 겹칩니다. T-2004가 김하늘의 11/5 회수 질문과 최영순의 11/6 혈압약 질문에 같이 쓰였습니다. T-2012는 최영순 목록에 두 번, 김하늘 목록에도 있고, 약사 화면의 T-2012는 또 다른 질문입니다.
- 같은 혈압약 질문이 T-2005로 하나 더 있습니다(이번 점검에서는 한 번만 보냄). 약사 화면 T-2007에 "119 버튼을 눌렀어요" 문구가 있습니다.
- 약사 화면 열린 접수 84건에서 새 긴급 건이 위로 올라오지 않습니다 (T-2004가 36번째, 맨 위 알림은 전날 T-2032).
- 11/5 14:46 김하늘 건은 담당자 이관인데 접수 번호가 "없음"입니다.

- 1-a 되묻기 문구 "더 알려 주세요: 어느 단계에서"가 중간에 끊긴 문장처럼 보입니다.
